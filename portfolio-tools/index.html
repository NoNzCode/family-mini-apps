About

为什么做这些小东西？

家里有学龄前的小朋友，也有想记录日常产出的大人。市面上的应用要么广告太多、要么要注册、要么把数据传到远方。

于是干脆自己写：单文件、零依赖、数据留在本地。游戏能离线玩，笔记能导出备份，识字题库能自己增删。这个小站把它们整理到一起，再放几个随手会用到的小工具。

  • 纯 HTML / CSS / JS，无构建、无框架、无 CDN
  • 数据存 localStorage，支持 JSON 导出导入
  • 断网也能打开，手机浏览器即用
  • 不收集、不上传任何个人信息
